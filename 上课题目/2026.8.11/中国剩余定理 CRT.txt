a[1] a[2] ... a[n] 两两互质
怎样寻找
m[1] m[2] ... m[n] 
满足
m[i] 是 a[1...n, 除了i] 的公倍数，并且模a[i]余1 

a[1...n, 除了i] 的公倍数 最小是
	a[1] * a[2] * ... * a[n]，除了a[i]
	M = a[1] * a[2] * ... * a[n]
a[1...n, 除了i] 的公倍数最小是 M / a[i]

k * (M / a[i]) = 1 (mod a[i])
求在模a[i]的意义下，(M/a[i])的逆元k
m[i] = k * (M / a[i]) 

注意：在计算m[i] * b[i]时，可能溢出（P1495）
可以用__int128来定义128位整数 

P12155
	a[1] =  20240413
	a[2] =  20250412
	N % a[1] = -9999
	N % a[2] = 9999
	
	2个数字的CRT
	方法二：

B4221
	一个周期为2pq秒，考虑第0,1,2...2pq-1这些时刻
	x时刻如果两个灯都是绿灯，需要满足
	x % 2p < p
	x % 2q < q
	对应若干个同余方程组
	x % 2p = a，其中0 <= a < p 
	x % 2q = b，其中0 <= b < q 
	这个方程在mod 2pq的情况下，如果有解，解是唯一的
	所以只需要统计有多少(a,b)满足方程有解
	(b-a)需要满足：它是2的倍数，它是gcd(p,q)的倍数
